# Block litix.io

A simple userscript for tampermonkey, violentmonkey, greasemonkey, etc that blocks litix.io beacon request spam on kick.com when using DNS level adblock or adblockers like uBlock Origin.

## Installation

Use the links below to install the userscript:

[Github Install](https://raw.githubusercontent.com/latelatelate/kick-litix/refs/heads/main/block.user.js)\
